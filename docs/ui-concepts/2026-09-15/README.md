# H2 Notes: 4 cặp mô phỏng UI

Ngày 15/09/2026. Đây là ảnh để lựa chọn bố cục, **không phải ảnh chụp app đã triển khai**.
Chưa sửa code app, dữ liệu hoặc cài đặt. Ảnh được tạo bằng công cụ image_gen tích hợp.

| Hướng | Bảng dự án | Ghi chú thường | Điểm đánh đổi |
| --- | --- | --- | --- |
| 1. Bảng tinh gọn | Bảng phân cấp, ghi chú bên phải | Note dọc, công cụ bên dưới | Nhìn nhiều dự án; hợp cửa sổ rộng |
| 2. Tập trung từng dự án | Danh sách trái, vùng làm việc bên phải | Trang viết có mục lục | Soạn nội dung dài tốt; ít tổng quan nhiều dự án |
| 3. Thẻ theo trạng thái | Các cột Cần làm / Đang làm / Chờ phản hồi | Nội dung theo khối | Trực quan; tốn diện tích, cần bổ sung trạng thái và khối |
| 4. Sổ dự án liền mạch | Từng mục mở rộng trực tiếp | Note ngang thấp | Gần cảm giác sticky note; mở nhiều mục sẽ phải cuộn |
