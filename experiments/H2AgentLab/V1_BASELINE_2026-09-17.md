## Known v1 limitations intentionally preserved as baseline, not accepted as final design

- OpenAI path uses Chat Completions rather than primary Responses/WebSocket agent transport.
- every model step receives the full detailed tool schema set.
- active context is based on recent journal/activity rather than a dedicated bounded context manager with compaction.
- `run_python` carries too much Office-domain responsibility.
- no live Excel/Word structured host for unsaved documents.
- desktop control is UI Automation-focused and lacks a full screenshot/vision observe-act-observe loop.
- semantic verification is incomplete; model self-review can still carry too much weight.

## Baseline rule

V2 work may add new tests and new execution paths, but a completed migration phase must not silently reduce this deterministic baseline. A deliberate replacement/removal requires a task ID in `AGENTLAB_V2_TASKS.md`, replacement coverage, and preserved historical evidence.
