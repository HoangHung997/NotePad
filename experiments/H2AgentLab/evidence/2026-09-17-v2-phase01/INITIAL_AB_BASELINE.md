## Important limitation

This is a **synthetic deterministic harness fixture**, not a real model/provider speed benchmark. The fake Ollama-style stream exists to prove that the instrumentation and comparison paths work and to expose structural request growth. Timing numbers below are CI/runtime overhead and must **not** be interpreted as model speed or a Codex comparison.

Real Ollama/OpenAI latency, token cost and quality benchmarking remains part of the later acceptance work.

- raw no-tool probe measures the same profile/prompt without Agent Lab tool context;
- current v1 direct loop exposes the extra request payload overhead;
- current v1 one-tool fixture measures continuation and tool overhead.

The meaningful deterministic observation is request structure/size:

- raw no-tool sent 86 bytes in the synthetic request payload;
- current v1 direct path sent 13,782 bytes because it adds Lab instructions/recovery/environment/session context and the complete tool schema set;
- one v1 tool round trip made two model calls and sent 28,062 bytes because the second request replays the enlarged transcript and tool schemas.

This validates the Phase 02/05 priorities: provider-native incremental continuation and deferred tool schema loading.
